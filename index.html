What CallQuarry Checks

Eight layers.
One report.

01
Manifest Linting
Validates Skill name, version, description, network declarations, entrypoints, and threat model shape against strict rules.
02
Prompt Attack Scanning
Detects instruction-override phrases, secret-exfiltration patterns, jailbreak wording, and hidden-output directives embedded in prompts or descriptions.
03
Test Vector Validation
Runs sample inputs through each entrypoint's declared JSON Schema to confirm they match before any live execution.
04
Pharos RPC Probing
Verifies RPC endpoints, confirms chain IDs, reads block height and gas price for Pharos Mainnet and Atlantic Testnet.
05
Read-Call Simulation
Executes declared JSON-RPC read probes — eth_getBalance, eth_call — without signing or spending.
06
Gas Dry-Run
Runs eth_estimateGas for declared transaction simulations. No signing, no broadcasting, no gas spent.
07
Wallet Proof Mode
Optionally signs a zero-value self-transfer on testnet or mainnet. Broadcast requires two explicit confirmation flags.
08
Readiness Report
Produces a scored JSON or text report — 100 points minus deductions per fail, warn, or skip — with a final status of ready, needs-review, or blocked.

Scoring

Validate, not guess. Score every layer.

Every check contributes to a score from 0 to 100. Failures cost 18 points each. Warnings cost 6. Skips cost 2. The final status tells the agent — and the judge — exactly how ready a Skill is.

READY Zero failures, zero warnings
NEEDS REVIEW Has warnings, no failures
BLOCKED One or more failures

CLI

Two commands.
Full coverage.

Run offline for instant schema checks, or live for full RPC validation. Wallet proof is always opt-in.

callquarry.mjs
# Step 1 — offline validation (no RPC needed)
$ node scripts/callquarry.mjs validate --manifest examples/pharos-balance-target.json --offline
Status: ready   Score: 100/100   0 failed
# Step 2 — live Pharos RPC check
$ node scripts/callquarry.mjs validate --manifest examples/pharos-balance-target.json --networks pharos-mainnet,pharos-atlantic-testnet
Status: ready   Score: 100/100   0 failed
# Step 3 — wallet dry proof (no gas spent)
$ node scripts/callquarry.mjs prove-wallet --network pharos-atlantic-testnet
Transaction signed   Transaction broadcast skipped
# Step 4 — broadcast proof (testnet, spends gas)
$ node scripts/callquarry.mjs prove-wallet --network pharos-atlantic-testnet --broadcast --i-understand-this-spends-gas
Transaction broadcast   0x18dd2d9dd7367...
# Save a JSON report
$ node scripts/callquarry.mjs validate --manifest examples/pharos-balance-target.json --format json --out reports/report.json

Target Manifest

One JSON.
Full context.

Every CallQuarry validation runs from a target manifest — a JSON file that describes your Skill's identity, networks, entrypoints, threat model, and test vectors. Start from the example and extend it.

name  ·  lowercase hyphen-case, 3–63 chars
version  ·  semantic version e.g. 0.1.0
networks  ·  array of Pharos network IDs
entrypoints  ·  callable functions with schemas
threatModel  ·  permissions, writes, secrets
pharos-balance-target.json 
{
  "name": "my-pharos-skill",
  "version": "0.1.0",
  "description": "Fetches native balance for a Pharos address.",
  "networks": [
    "pharos-mainnet",
    "pharos-atlantic-testnet"
  ],
  "entrypoints": [{
    "id": "getBalance",
    "type": "read",
    "description": "Fetch native balance for address.",
    "inputSchema": {
      "type": "object",
      "required": ["address"]
    }
  }],
  "threatModel": {
    "permissions": ["rpc-read"],
    "writes": false,
    "secrets": []
  }
}

Safety First

Read-only
by default.

The core validator never signs, never broadcasts, never spends gas. Wallet proof mode is an explicit opt-in with layered confirmation guards.

Never commit private keys
Set PHAROS_PRIVATE_KEY in your shell only. Never paste it into a manifest, README, or argument.
Explicit gas consent
Broadcasting requires both --broadcast and --i-understand-this-spends-gas. Mainnet additionally requires --allow-mainnet.
Offline-first
Run --offline for your first pass. Catches manifest, schema, and prompt issues without any network access.
● Safe — no gas
npm run validate
npm run validate:live
node scripts/callquarry.mjs prove-wallet \
--network pharos-atlantic-testnet
node scripts/callquarry.mjs prove-wallet \
--network pharos-mainnet --allow-mainnet
● Broadcasts — spends gas
node scripts/callquarry.mjs prove-wallet \
--network pharos-atlantic-testnet \
--broadcast --i-understand-this-spends-gas
